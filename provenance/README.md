# Release provenance

This is a clean file export of Peter Neyra's owned route-planning application, originally developed within Vitrina. The source interface and routing corrections were retained while commercial inputs were independently authored for a public example.

`code-source.json` records the code lineage, pre-export source hashes and omitted material. `fixture.json` records the new dataset contribution and file hashes. `release-checks.json` records completed offline verification and outstanding live proof. Earlier private Git history is outside this export because it contains the historical sourced catalogue.

The original source and source-backed Barcelona case remain privately preserved. The public example's MIT licence covers original code and newly authored commercial inputs. Map, routing and library terms are tracked separately in `THIRD_PARTY.md`.
